# Porting the `jev` branch (requirement tracker) onto `nextversion`

The `jev` branch holds the requirement tracker ("Követelmények"): rules engine, extraction (pattern parser + the Jev/TypeSafe AI survey), results, calendar links, catch-up popup, the extended header bell, shared rule templates per university, Jev suggestions (course/component/duplicate), Neptun semester detection and group mapping, and digest "Rögzítésre vár". It forked on 2026-10-06, before main dropped the tracker and before the English version, the demo, the legal pass, the consistency pass and the UX enhancements.

**Status (2026-10-22): all phases done, design-reviewed and browser-checked in the demo; see `docs/PLAN.md`. What follows is the state at the start of the port.**

**State then (uncommitted in the working tree of `nextversion`):** every `jev` change since `2466828` is merged in, conflicts resolved, `lib/legacyRequirements.ts` (which stripped tracker data) is deleted, `pdfjs-dist` is installed (owner approved), study blocks are kept (jev had removed them; main still ships them), jev's `useConfirm` callers use the current API (`const { confirm: ask, dialog: confirmDialog } = useConfirm()`). The owner's previous uncommitted work is backed up on the local branch `nextversion-ux-backup`. `npm test`: 387/388 pass (the digest subject test waits on phase A). `tsc`: only `app/api/*` errors left (phase A).

**What is NOT done:** jev's code is Hungarian-only (raw strings everywhere, `errorResponse("text", status)`, raw `text-[14px]` sizes). Every phase below fixes that for its area.

**Reference for how the tracker works:** `git show jev:CLAUDE.md` (bullets "Jev suggestions", "Course requirements", "Requirement links, catch-up, reminders (M2)", "Timetable (Neptun)"), and `git show jev:<path>` for any file's jev version. Phase C copies those bullets into `CLAUDE.md`, adapted.

## Rules for every phase

- Follow `CLAUDE.md` / `AGENTS.md` / `DESIGN.md`. Work in the main checkout, branch `nextversion`; never switch branches, never commit, never `git stash`/`reset`/`checkout` files.
- **i18n:** no raw UI strings in components; `lib/i18n/hu.ts` is the source (`as const`, nested by area, functions for counts/variables), `en.ts` typed against it. Add the tracker's strings in new groups (e.g. `requirements`, `rules`, `survey`, `catchUp`, `university`, `suggest`…). Client: `useT()`/`useLocale()`; server routes: `errorResponse(locale, code, status)` with codes in the `errors` group and `requestLocale(req)` / `auth.deps.locale ?? "hu"` like `app/api/fiok/hirlevel/route.ts`; `guarded(req, …)`. Pure libs that produce user-visible text take an optional `locale` (default `"hu"`) and stay React-free; they may import `getMessages(locale)` from `lib/i18n`. Concise professional Hungarian; natural English.
- What stays Hungarian on purpose: the extraction lexicon/patterns (they read Hungarian documents), Jev prompts (English already), user data (component labels from the document, course names), fixtures.
- **Type ramp and tokens:** replace raw sizes (`text-[13px]`, `text-[14px]`, `text-[13.5px]`, `text-[10.5px]`…) with the `--text-*` utilities (`text-fine/small/body/lead/title/subhead…`), radius literals with `--radius*` tokens, raw checkboxes with `components/ui/Checkbox`, icon-only buttons with `IconButton`, text links with `.link-text`, hover washes `bg-wash/[…]`. No raw hex outside the allowed places.
- **Demo mode:** anything that calls the server (Jev survey `/api/kovetelmeny/elemzes`, suggestions `/api/javaslat`, templates `/api/kovetelmeny/sablon`, university `/api/fiok/egyetem`) must not run in the demo (`useDemoMode()`): show `DemoLocked` or fall back to the local path (the pattern parser) silently.
- Tests: keep `npm test` green; tests import only React/zustand-free modules. Run `npm run lint && npm run build && npm test` at the end of each phase and fix failures.
- Report: files changed, decisions, anything unsure.

## Phase B: rules library user-facing text

`lib/rules/*` produce Hungarian text shown in the UI: `validate.ts` errors, `describe.ts`, `engine.ts`/`solve.ts`/`standing.ts` statuses and risks ("Még 1 hiányzás fér bele"…), `extract/survey/read.ts` reasons and `fields.ts` labels/`consistency` messages, `extract/survey/rules.ts` errors and flags, `extract/assemble.ts` questions, `extract/semantic.ts`, `instances.ts` labels (`instanceLabel`, `shortDayLabel`), `links.ts`, `lib/catchup.ts`, `lib/reminders.ts`, `lib/notifications.ts` (`catchUpNotification`). Give each an optional `locale` parameter (default `"hu"`) and move the wording into the dictionary (functions for variables), keeping the Hungarian output byte-identical so the existing tests still pass; add English assertions for a representative sample. Do not translate the extraction lexicon or Jev prompts. If a message is stored inside data (e.g. rule flags saved into `SubjectRules`), keep storing a stable code or the Hungarian text as jev did and translate at display time; note what you chose.
